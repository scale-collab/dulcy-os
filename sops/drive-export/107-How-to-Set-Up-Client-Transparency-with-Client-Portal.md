How to Set Up Client Transparency with Client Portal


1. Purpose
This SOP explains how to use the Dulcy Client Portal as the single source of truth for each client:
* So they can see their own performance and assets without asking you.

* So you aren’t hunting through Slack DMs and random docs.

* So every CSM / team member sees the same information in one place.

The goal: everything related to the engagement lives in the portal — campaigns, assets, logins, tasks, feedback, etc.
________________


2. When to Use This
Use this SOP:
   * Right after a client signs and pays (during onboarding).

   * Any time you create new campaigns, upload assets, or change logins.

   * Any time the client sends you something important (decks, scripts, case studies, etc.).

The portal should always be kept up-to-date in real time as things change.
________________


3. Tools Used
      * Client Portal: portal.dulc.io

      * Airtable: Dulcy operating system

         * Client Portals table (or equivalent)

         * Workspace IDs / Clients table

         * Documents & Info tables

         * Client Tasks

         * Campaigns / Campaign Thesis

         * Call Feedback

________________


4. Step 1 – Make Sure Client Has Portal Access
            1. Send the client the portal sign-up link:

portal.dulc.io/signup (or your current sign-up URL).

            2. Client signs up with their email + password.

            3. By default, after signup, they see nothing until you connect them to the right workspace from Airtable.

________________


5. Step 2 – Link Portal Account to Client Workspace
               1. In Airtable, go to the table that tracks Client Portals / users.

               2. Find the row that matches the client’s portal email.

               3. In the column that links them to a Workspace / Agency, click the + and select the correct client workspace (e.g., “KNR Paris”, “Lucky Diem”, etc.).

               4. Once linked:

                  * Airtable will auto-populate fields like:

                     * Created date

                     * Last seen

                     * Workspace ID / Client record ID

                        5. Ask the client to refresh the portal. They should now see:

                           * A welcome screen with their name.

                           * The navigation to Analytics, Tasks, Onboarding, Logins, Docs, Campaign Thesis, Call Feedback, etc.

________________


6. Step 3 – Explain the Portal Layout to the Client
On your onboarding call, walk them through the portal live so they know how to use it.
Key sections to show:
6.1. Overview / Home
                              * “Welcome to Dulcy, [ClientName]…”

                              * Explain: “This portal is where you’ll find all campaigns, stats, assets, and logins. If you ever lose something in Slack, check here first.”

                              * Show them the Book a Call button:

                                 * This is how they can quickly book time with you / your team.

6.2. Email Analytics
Show them how to:
                                    * Select timeframe: Last 10 / 30 / 60 / 120 days / All time.

                                    * Read the top-level stats:

                                       * Emails sent

                                       * Replies

                                       * Positive replies

                                       * Meetings booked

                                       * Reply rate, positive reply rate

                                       * Meeting-booked rate

                                       * “Emails to book 1 call”

                                          * Scroll down to campaign-level details:

                                             * Campaign name

                                             * Status

                                             * Total leads contacted

                                             * Meetings booked

                                             * Copy performance

Explain:
“This is where you can see what’s happening with your campaigns without asking us for screenshots. If a board member asks ‘Is this working?’, these are the numbers to show them.”
6.3. LinkedIn Analytics
If applicable:
                                                * Show they can see:

                                                   * Invites sent

                                                   * Replies

                                                   * Positive replies

                                                   * Meetings booked

                                                      * Show messaging logs per lead if available.

6.4. Tools
                                                         * Show the Dulcy ESP / sending tool link inside the portal.

                                                         * Explain that in the future, other tools (like voice AI) will appear here as well so everything is central.

7. Step 4 – Using Task Requests in the Portal
Clients often forget what you asked them for. Task Requests fix that.
                                                            1. In Airtable, go to Project Management → Client Tasks (or your equivalent).

                                                            2. Create a new task anytime you need something from the client. For example:

                                                               * “Upload your pitch deck”

                                                               * “Share your best-performing landing page”

                                                               * “Send us 3 client testimonials”

                                                                  3. Fill out:

                                                                     * Task name

                                                                     * Description / what exactly you want

                                                                     * Attach to the right Client Workspace

                                                                        4. Once saved, the task auto-syncs into the Task Requests section in the client portal.

                                                                        5. In the portal, the client sees:

                                                                           * Task title

                                                                           * Description

                                                                           * Status (e.g., To do / Done / Blocked)

Tell the client:
“Any time we need something from you, it’ll appear in the Tasks area of the portal. When you finish it, just mark it done there instead of telling us only in Slack.”

8. Step 5 – Onboarding Form in the Portal
The Onboarding Form is the core reference for their:
                                                                              * ICP

                                                                              * Offer(s)

                                                                              * Pricing

                                                                              * Key assets and logins

                                                                              * Notes about their product/service

How to manage it:
                                                                                 1. After they sign, they fill the Onboarding Form (or you fill it on the call).

                                                                                 2. The form auto-populates into the Onboarding section of their portal.

                                                                                 3. They (and you) can:

                                                                                    * Edit fields

                                                                                    * Update answers

                                                                                    * Keep details current (new offers, new markets, etc.)

You should:
                                                                                       * Encourage them to update it instead of sending random updates in Slack.

                                                                                       * Use it as your source of truth when building campaign theses and copy.

________________


9. Step 6 – Logins Tab
All client-related logins should live here.
Examples:
                                                                                          * Email accounts:

                                                                                             * alex@clientdomain.com / password

                                                                                                * Domain registrar access (if shared)

                                                                                                * Calendly/booking links

                                                                                                * Any tool access needed for outbound execution.

Flow:
                                                                                                   1. When you create new sending accounts for them, add:

                                                                                                      * Email

                                                                                                      * Password

                                                                                                      * Any notes needed

                                                                                                         2. When they share logins in Slack, copy them into the Logins tab.

                                                                                                         3. Tell the client:

“All sending logins and domains we create for you will be stored in the Logins tab. If you ever need to see what exists or lose track of login details, check here first.”
________________


10. Step 7 – Documents & Information
This is the central document library for the engagement.
There are two flows:
10.1. Client Uploads
In the portal, the client can:
                                                                                                            * Go to Documents / Info

                                                                                                            * Click Add / Upload

                                                                                                            * Upload:

                                                                                                               * Sales scripts

                                                                                                               * Decks

                                                                                                               * Case studies

                                                                                                               * Brand guidelines

                                                                                                               * Loom links, etc.

Use-case:
“If you have a new deck you want us to reference for copy, upload it here. Don’t just drop it once in Slack.”
10.2. You Upload (Dulcy-side)
To add something from your side:
                                                                                                                  1. In Airtable, go to the “Add New Document / Info in Client Portal” tool (or the relevant table).

                                                                                                                  2. Fill in:

                                                                                                                     * Title (e.g., “Cold Email Script V1 – Agencies”)

                                                                                                                     * Description (e.g., “Primary script for Campaign 1 thesis”)

                                                                                                                     * Attachment (PDF, Docs link, Loom link, etc.)

                                                                                                                     * Workspace / Client (attach to correct workspace)

                                                                                                                        3. Save.

Result:
                                                                                                                           * In the portal, under Documents & Info, the client now sees your upload.

                                                                                                                           * There will be a field indicating whether it was uploaded by Client or Dulcy:

                                                                                                                              * This makes it easy to filter:

                                                                                                                                 * “Show me only what Dulcy shared with us”

                                                                                                                                 * “Show me only what we uploaded to Dulcy”

Rule:
Anything important you share (scripts, decks, analyses) must be uploaded here, not left buried in Slack.
________________


11. Step 8 – Campaign Thesis Visibility
Every campaign you create should have a campaign thesis that flows into the portal.
From your side:
                                                                                                                                    1. In Airtable, go to Campaigns.

                                                                                                                                    2. For each new campaign, fill the Thesis / Strategy fields:

                                                                                                                                       * Objective / angle

                                                                                                                                       * ICP / segment

                                                                                                                                       * Offer being used

                                                                                                                                       * Overview of the copy / hooks

                                                                                                                                       * Loom link walking through the thesis (if recorded)

                                                                                                                                       * Lead list notes

                                                                                                                                       * Scripts you’re testing

Because of the integration:
                                                                                                                                          * Those theses appear in the client portal under Campaign Thesis (or similar section).

                                                                                                                                          * Client can open any thesis and see:

                                                                                                                                             * Loom video (if added)

                                                                                                                                             * Written thesis

                                                                                                                                             * Lead list details

                                                                                                                                             * Scripts being tested.

Explain to the client:
“If you ever want to see what we’re testing and why, open the Campaign Thesis section. Every new campaign’s logic and assets are documented there.”
________________


12. Step 9 – Call Feedback via Portal
We need to know what happens on the calls we book. The Call Feedback section makes that trackable.
Flow:
                                                                                                                                                1. When a lead is marked as “Won / Meeting Booked” in Airtable, we store the Date of Call.

                                                                                                                                                2. The day after the call date, the client receives a Slack ping like:

                                                                                                                                                   * “Please give 30 seconds of call feedback for [LeadName]. Here’s the link to the form.”

                                                                                                                                                      3. The form is also accessible in the portal:

                                                                                                                                                         * Call Feedback Missing → opens the same form.

The client fills:
                                                                                                                                                            * Whether the call was:

                                                                                                                                                               * No-show

                                                                                                                                                               * Rescheduled

                                                                                                                                                               * Qualified / Not Qualified

                                                                                                                                                                  * Rating (1–5 stars)

                                                                                                                                                                  * Link to call recording

                                                                                                                                                                  * Notes / next steps

All submissions flow into:
                                                                                                                                                                     * Call Feedback in the portal (past feedback list)

                                                                                                                                                                     * Airtable tables for internal tracking.

Explain to client:
“We need you to spend 30 seconds after each call to fill this form. It helps us understand if the calls we’re booking are qualified and where we can improve.”
________________


13. Best Practices
For CSMs and team:
                                                                                                                                                                        * If it’s important, it belongs in the portal.

                                                                                                                                                                           * Docs, scripts, logins, theses, feedback, tasks.

                                                                                                                                                                              * Keep Slack for:

                                                                                                                                                                                 * Quick back-and-forth.

                                                                                                                                                                                 * Notifications and reminders.

                                                                                                                                                                                    * Keep the portal for:

                                                                                                                                                                                       * Permanent reference and history.

For clients:
                                                                                                                                                                                          * Remind them regularly:

                                                                                                                                                                                             * “If you’re looking for stats, logins, or documents – it’s all in the portal.”

                                                                                                                                                                                                * On every ops review call, briefly open the portal and show:

                                                                                                                                                                                                   * Analytics

                                                                                                                                                                                                   * Recent campaign theses

                                                                                                                                                                                                   * Any new docs you’ve added.

________________


That’s it. Once this is in place and you’re disciplined about using it, the client portal becomes the live dashboard of the relationship, and you avoid 90% of “Can you resend that?” chaos.
