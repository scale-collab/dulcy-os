﻿How to Navigate Heyreach SOP
HeyReach - 15 December 2025


1) Purpose
This SOP explains how to navigate HeyReach, connect LinkedIn sender accounts, and create/run LinkedIn campaigns correctly—either standalone or synced with Dulcy campaigns—so outbound LinkedIn activity runs safely, consistently, and at scale.
Use this SOP anytime:
* A new client is onboarded with LinkedIn outreach

* A LinkedIn sender needs to be connected

* A LinkedIn campaign needs to be created or launched

________________


2) Outcome
When completed correctly:
   * LinkedIn sender accounts are securely connected to HeyReach

   * Campaigns are named and structured correctly for Dulcy integrations

   * LinkedIn connection requests and follow-ups send automatically

   * Replies flow into RevReply for inbox management

________________


3) Tools / Access Needed
      * HeyReach account access

      * Client LinkedIn login credentials

      * Client LinkedIn 2FA secret key (NOT the 6-digit code)

      * Authenticator app enabled on client’s LinkedIn

      * Airtable access (for Dulcy-linked campaigns)

      * RevReply (for inbox management)

________________


4) Prerequisites
Before starting:
         * Client onboarding completed

         * LinkedIn account has two-factor authentication enabled

         * Client has provided the 2FA secret key (long key string)

         * Workspace for the client already exists in HeyReach

________________


5) Step-by-Step Process
A. Navigate Workspaces
            1. Log into HeyReach.

            2. You’ll see:

               * A master view (overview only)

               * Individual client workspaces underneath

                  3. Do NOT attempt to manage campaigns from the master view—campaign actions only work inside client workspaces.

________________


B. Manage Seats (If Needed)
                     1. Go to Settings → Workspaces / Billing.

                     2. Click Manage Seats.

                     3. Add or remove seats depending on the client.

Rules:
                        * Dulcy Growth Partnership includes 1 LinkedIn sender

                        * Each additional LinkedIn sender = $100/month extra

                        * Example:

                           * Client on $4,000/mo package

                           * Adds 3 extra LinkedIn senders

                           * New total = $4,300/mo

________________


C. Connect a LinkedIn Account (Critical Step)
                              1. Go to LinkedIn Accounts.

                              2. Click Connect Account.

                              3. Select Infinite Login.

                              4. Choose Yes, I have two-factor authorization.

Important rules:
                                 * You MUST use the 2FA secret key, not the rotating 6-digit code.

                                 * The secret key is a long string.

                                 * If client sends only the 6-digit code → STOP and request the correct key.

                                    5. Enter:

                                       * LinkedIn email

                                       * LinkedIn password

                                       * 2FA secret key

                                          6. Conversation tracking:

                                             * Select Track only conversations started from HeyReach

                                                7. Proxy:

                                                   * Default location unless client is international

                                                      8. Click Connect Account

Sender limits (default):
                                                         * 20 / 20 / 20 / 20 / 40 / 40

                                                         * This equals ~100 connection requests per week (LinkedIn safe limit)

________________


D. Viewing Performance & Stats
                                                            1. Filter by sender (ex: Alexander Wong).

                                                            2. Review:

                                                               * Connection requests sent

                                                               * Acceptance %

                                                               * Messages sent

                                                               * Reply rate

                                                                  3. Use date filters to review performance by time range.

________________


E. Campaign Creation (Dulcy-Linked Campaigns)
Naming Rules (VERY IMPORTANT)
                                                                     * Campaign name in HeyReach must exactly match the campaign name in:

                                                                        * Dulcy email sending tool

                                                                        * Airtable

                                                                           * This is how the systems auto-connect.

Example:
Dulcy PPC Agency – A-Leads – Direct Offer
