🧾 Objective
To ensure that all calendar invites for the executive are scheduled correctly, contain the necessary information, and are shared with the right people using Calendly, Motion, or Zoom.
________________


🧩 Scope
This SOP applies to all new meeting invitations created by the EA on behalf of the executive, whether internal, external, or personal. It includes scheduling through Calendly links, directly in Motion, or via Zoom.
________________


🧑‍💼 Responsibilities
The Executive Assistant is responsible for:
* Creating and sending meeting invitations

* Ensuring all details are correct and complete

* Adding correct video links and notes

* Managing any changes or reschedules

________________


🔁 General Steps (All Invites)
   1. Confirm Meeting Details:

      * Who: Attendees (name + email)

      * What: Meeting purpose

      * When: Date and time (time zone sensitive)

      * Where: Video call link or location

      * How long: Duration (default: 30 or 45 mins)

         2. Choose Invite Type:

            * Calendly: For allowing invitees to choose from available slots

            * Motion: For manually scheduling into the executive’s calendar

            * Zoom: For instant scheduling or adding to an invite

               3. Add Clear Title:
Example: Client Intro – John Doe (Acme Corp)


 Avoid vague titles like “Call” or “Meeting”


               4. Add Description & Context:
Include:

                  * Agenda or purpose

                  * Meeting link

                  * Prep docs (if any)

                  * Attendees + their roles

                     5. Set Correct Time Zone:
Always double-check if invitees are in different time zones.

                     6. Send Invite from the Executive’s Calendar:
Add executive as Organizer or Host. If sending on their behalf, mark "via EA" in the message if needed.

________________

🧠 Invite Method #2: Creating Directly in Motion
Use this when you need to schedule a specific meeting manually.
Steps:
                                 1. Open the executive’s Motion calendar

                                 2. Click desired time slot → “Create Event”

                                 3. Add:

                                    * Title (clear and specific)

                                    * Guests (emails)

                                    * Duration (15, 30, 45, 60 mins)

                                    * Description (agenda, prep docs)

                                    * Location (Zoom/Google Meet link)

                                       4. Set to “Busy” or “Free” as needed

                                       5. Attach any related task (if applicable)

                                       6. Save and send invite

✅ Tip: Use “Fixed Time” for meetings that should not be moved by Motion’s auto-scheduler.
________________


📹 Invite Method #3: Scheduling via Zoom
Use this when:
                                          * You need a Zoom link before creating a calendar event

                                          * No Calendly integration is used

Steps:
                                             1. Log into the executive’s Zoom account

                                             2. Schedule a meeting:

                                                * Title: Match meeting name

                                                * Time: Exact time

                                                * Duration: Set correctly

                                                * Video: On for host & participants

                                                * Waiting Room: ON for external guests

                                                   3. Copy Zoom Meeting Link

                                                   4. Create a calendar invite in Motion or Google/Outlook:

                                                      * Paste Zoom link in the location

                                                      * Add title, guests, agenda

                                                      * Set reminders (15 min before)

✅ Make sure host is assigned as the executive (not you)
________________


🛑 What NOT to Do
                                                         * Don’t send invites without confirming the executive’s availability

                                                         * Never leave out a meeting link or agenda

                                                         * Avoid overlapping meetings unless it’s approved

                                                         * Don’t use abbreviations in titles unless understood by all invitees

                                                         * Never send invites from your personal calendar

________________


🔁 Rescheduling a Meeting
If a meeting needs to be moved:
                                                            1. Check executive availability first

                                                            2. Offer 2–3 alternative time slots

                                                            3. Use Calendly link if rescheduling externally

                                                            4. Update calendar invite and notify all guests

                                                            5. Confirm the reschedule appears in Motion
