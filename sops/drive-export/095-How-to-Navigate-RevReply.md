2) Purpose
This SOP explains how to navigate RevReply once it has already been set up. It covers how to monitor inbox managers, review messages, track replies and meetings, and ensure inbox performance stays aligned with campaign activity.
Note: This SOP does not cover initial setup. Setup instructions live in the Inbox Management SOP.
________________


3) Outcome
By following this SOP, the user will be able to:
* Monitor inbox manager performance across all clients

* Review replies, follow-ups, meetings booked, and failures

* Navigate messages efficiently using filters

* Verify inbox managers are correctly configured and active

* Keep reply handling aligned with live outbound campaigns

________________


4) Tools / Access Needed
   * RevReply account access (invited via team workspace)

   * Connected inbox managers (already configured)

   * Integrated tools (EmailBison / HeyReach / Calendars)

________________


5) Prerequisites
Before using RevReply:
      * Inbox managers must already be created and configured

      * Email and LinkedIn accounts must be connected

      * Calendars and booking links must be live

      * Client campaigns must be actively sending

________________


6) Step-by-Step Process
Step 1: Log In & Confirm Team Workspace
         1. Log into RevReply

         2. You will automatically land inside the team workspace

         3. Confirm you can see all inbox managers for active clients

Rule:
We use one team workspace, not multiple workspaces.
________________


Step 2: Review Dashboard Metrics
On the main dashboard, you will see:
            * Total messages sent

            * Total meetings booked

            * Total follow-ups due

These metrics are shown:
               * Across all inbox managers

               * For all time

               * With filters available to narrow results

Quality Check:
Dashboard activity should generally align with campaign activity in EmailBison / HeyReach.
________________


Step 3: Navigate Inbox Managers
                  1. Click Inbox Managers in the left menu

                  2. Here you can:

                     * View all inbox managers

                     * Toggle managers on/off

                     * Edit auto-responder behavior

                     * Search managers by name

                     * Duplicate or delete managers

                     * Access advanced settings

                     * Open the setup wizard (same as initial setup flow)

Rule:
Do not modify advanced settings unless instructed.
________________


Step 4: Verify Inbox Manager Configuration
For each inbox manager, confirm:
                        * Objective is clearly defined

                        * Correct email accounts are connected

                        * LinkedIn (HeyReach) integration is correct if used

                        * Calendar integration and booking links are correct

                        * Company information is properly filled in

                        * Auto-response configuration matches the client strategy

This ensures replies are handled correctly and meetings book properly.
________________


Step 5: Use the Messages Section (Core Workflow)
The Messages section acts as a unified inbox.
From here you can:
                           * View all inbound messages

                           * See sent messages

                           * Review drafts not yet sent

                           * Identify failed messages

                           * Track canceled meetings

                           * See follow-ups that are due

________________


Step 6: Filter Messages Efficiently
Inside Messages, you can filter by:
                              * Inbox manager

                              * Manager type

                              * Lead category / tag

                              * Keywords (has words / doesn’t have words)

                              * Subject

                              * Sender / recipient

                              * Email account type

                              * Date range

You can also search by:
                                 * Name

                                 * Email

                                 * Subject line

Rule:
Always filter before acting on messages at scale.
________________


Step 7: Airtable Integration (Reference)
RevReply is integrated with Airtable.
                                    * Message status, tags, and outcomes will sync automatically

                                    * Updates can be managed directly from Airtable once live

Rule:
If data looks off in RevReply, cross-check Airtable.
________________


Step 8: Resources Tab (Optional)
RevReply provides a Resources section with documentation and guides.
Note:
This is optional reading and not required for daily operations.
________________


7) Quality Checks
Before concluding review:
                                       * Inbox managers are active (not accidentally paused)

                                       * Calendar bookings are functioning

                                       * Follow-ups are being addressed

                                       * Dashboard metrics align with outbound volume

                                       * No backlog of failed or unhandled messages

________________


8) Output / Handoff
                                          * Replies are handled automatically or manually via RevReply

                                          * Meetings are booked and synced to calendars

                                          * Statuses and outcomes sync to Airtable

                                          * Campaign performance continues uninterrupted

________________


9) Troubleshooting
Issue: Meetings not booking
                                             * Check calendar integration

                                             * Verify booking link inside inbox manager

                                             * Confirm availability settings

Issue: Replies not appearing
                                                * Confirm inbox manager is active

                                                * Verify correct email / LinkedIn account is connected

                                                * Check filters are not hiding messages

Issue: Follow-ups piling up
                                                   * Filter by “Follow-ups Due”

                                                   * Address oldest first

                                                   * Review auto-responder logic
