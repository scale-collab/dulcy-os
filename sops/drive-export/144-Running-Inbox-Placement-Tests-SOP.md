﻿Running Inbox Placement Tests SOP


Video Walkthrough: HERE


1. Log into Dulcy and select a workspace of the client.
  



2. Select Campaigns
  



3. Go into the Campaign needed for the test and select “Inbox Placement Tests” then press the blue button “New Inbox Placement Test”
  



4. Then press “Start Test”


  



5. After 15-30 minutes, the tests will be complete. If you go back to “Inbox Placement Tests” screen you will see the scores of all the inboxes for that test. Please report to the team via Slack or text if an inbox reports an overall score of >60%. These inboxes will be replaced. In the future I’ll add how you can do that.
