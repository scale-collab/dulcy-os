Understanding Close CRM Setup
  

1. When you log into the CRM, this is the first page you’ll see:
        •        Today’s Tasks: You’ll see the tasks that are due for the day.
        •        Missed Emails, Calls, Texts, or Reminders: Any missed messages or reminders from recent prospects or clients will show up here.
At the start of your day:
        •        Complete any tasks listed for you.
        •        For missed emails from recent prospects or clients, let the team know.
  

2. This is the Opportunities (Sales Pipeline) section. It shows all the booked calls that are still in progress and haven’t been marked as won or lost yet. For now, the team will handle most of the follow-ups here.
  

3. This is the Leads area, where all our prospects are listed. The most recent interactions are shown at the top, with older ones further down.
  

4. In “Smart Views,” you’ll find saved filters, and this is where all Cold Calling happens. All active leads from our shared Google Sheet will appear here.
  

5. Left Side: You’ll see information about the prospect or client, like their website, tasks, opportunities, email, phone number, lead source, and last meeting details. You’ll also find links to join or reschedule meetings and watch past Zoom recordings.


Right Side: This shows all the recent activity for the client.


Top: You can add notes, send emails, send a text, or make a call.


  

6. In the top right corner, you can change the settings for phone calls. 262-624-1152 is our business number, and it should already be selected.


You can also adjust your microphone and speaker settings before making a call. Once everything is set, just go to the lead and press Call. All calls are automatically recorded.


  
  

7. When you’re writing an email, a box will pop up where you can enter the subject and body of the message. You can either send the email right away or schedule it to go out at a specific time and date.


In the “From” box, you’ll see all the business emails you can send from. Make sure to select your email before sending, unless I’ve asked you to send it on my behalf.

Calendar Management in Motion


  

1. This is the main page you see when you log into Motion. Motion is an AI calendar that automatically moves your meetings and tasks, so you don’t have to do it yourself.
There are 3 main sections we use:
        •        Dulcy Media
        •        Personal Events
        •        Real Estate
Here’s how the screen is set up:
        •        Left Side: You’ll see the next task at the top. You can also add new tasks or projects, view the current calendar, and check “My Tasks,” “All Tasks,” and “All Projects.”
        •        Middle: This shows the current week. You can change the week by clicking the top left, next to the month.
        •        Right Side: You’ll see the day’s agenda and a bigger calendar at the top right.
This setup helps you see your schedule for the week and know what’s coming up!
  

2. The “Create Task” screen is where we add new tasks to the calendar. There are a few important parts:
        •        Task Name: The name of the task you’re adding.
        •        Description: You can add extra details if needed.
On the right side, you can:
        •        Assign the Task: Choose who will work on it (like yourself).
        •        Add to a Project: Pick a project if the task is part of one we’re working on.
        •        Set as To-Do: A new task can just stay in the “To-Do” list until it’s ready to be worked on.


Priority is one of the most important settings. Here’s what each priority level means:
        •        ASAP: This task is the most important and should be done right away.
        •        High: This is the main task to focus on today, the second most important.
        •        Medium: This is not urgent, but try to do it if you have extra time.
        •        Low: This can be done whenever there’s spare time, and isn’t a priority.


Duration is another important setting. It tells how much time should be blocked on the calendar to finish the task. Tasks can vary in length depending on what they are, but most usually take around 30 minutes to 1 hour.
*Min Chunk: Use this when a task doesn’t need to be finished in one sitting. For example, if creating a campaign is a 1-hour task, you could set it as two 30-minute chunks. This helps break down bigger tasks into smaller, manageable parts that the AI will categorize.

Start Date: The day we begin the task. 
Deadline: This is the date the task must be done by. Even if a task doesn’t have a deadline, we still aim to finish it quickly. For example, if Alex needs to build an automation, it might take 4-8 hours, broken into 30-minute chunks. It doesn’t have a strict due date, but it should ideally be done by the end of the week. There is a toggled for a hard deadline which will recategorize the calendar to make sure that task is done by that deadline.
  

3. There’s an automation set up so that whenever we sign a new client, a task will automatically appear in the Motion calendar (set to ASAP). This task will remind you to start the project.


There are 2 project types already set up:
        1.        Done-For-You
        2.        Lead List
The automation will separate these based on the type of project.
When you see this task appear (you’ll also get a Slack notification when a client signs), your job is to start the project and give it a title. Use the client’s name followed by their company in parentheses. For example: Greg Deemy (TargetonStar).

3. Use the calendar to assist with booking meetings with prospects.


One of the main things you’ll use the calendar for is to book meetings with prospects through the inbox manager and Calendly. It’s important to space out meetings well. My meeting hours are 9 AM - 5 PM EST, but if the prospect is in Australia, we can extend to 6 PM EST.


Preferred Meeting Times:
        •        Between 10 AM and 4 PM EST.
Recurring Tasks:
        •        You’ll see tasks like “follow up with prospects” or “check email list.” These are general daily tasks, so you can work around them when scheduling meetings.
Lunch Break:
        •        The 12 PM - 1 PM EST slot is usually marked for lunch. However, this can be flexible, so feel free to book meetings during this time if needed. We’ll let you know in advance if there are any specific changes.
