📁 Standard Operating Procedure (SOP)
Keeping Documents Organized in Google Drive
 For the Executive, EA, and Team Members
* Role: Executive Assistant

* Owner: [EA Name]

* Effective Date: [Insert Date]

* Last Reviewed: [Insert Date]

________________


🧾 Objective
To maintain a clean, accessible, and structured Google Drive workspace for the Executive, EA, and team members—supporting fast document retrieval, streamlined collaboration, and secure file sharing.
________________


🧩 Scope
This SOP applies to all Google Drive files and folders related to:
   1. The Executive’s documents (strategic, confidential, or presentation-based)

   2. The EA’s operational and support documents

   3. The Team Members’ shared project or cross-functional documentation

________________


🧑‍💼 Responsibilities
The Executive Assistant is responsible for:
      * Creating and maintaining the folder structure in Google Drive

      * Naming and organizing documents consistently

      * Controlling access and permissions

      * Archiving outdated files

      * Ensuring real-time collaboration and avoiding file duplication

________________


📁 Folder Structure Overview
📌 Root Folder: /[Company Name] Workspace/
Folder Name
	Purpose
	📂 1_Executive
	Strategic files, presentations, confidential
	📂 2_EA_Admin
	Calendar, travel, SOPs, event planning
	📂 3_Team Projects
	Project folders by team, department, or name
	📂 4_Archives
	Archived or completed documents
	📂 5_Templates
	Reusable files (decks, briefs, SOPs, forms)
	Each folder includes a README file or Google Doc with naming rules and owner details.
________________


🔁 Workflow for Organizing Executive Files
✅ 1. Document Intake
When receiving or creating files for the executive (e.g., board decks, memos, contracts):
         * Upload immediately to /1_Executive/[Project/Topic]

         * Rename using the naming convention (see below)

         * Share with the executive using “Viewer” or “Editor” based on needs

📛 Naming Convention (for all files)
css
CopyEdit
            * [Date]_[Document Title]_[Version]  
            * Example: 2025-07-01_BoardDeck_Q3Review_v2


🔐 Permissions
            * Only the Executive and EA should have access to /1_Executive

            * Sensitive files should be “Restricted” or viewable by specific people only

________________


🧍 Workflow for EA Documents
✅ 1. Use /2_EA_Admin for Personal EA Operations
Subfolders:
               * Calendar & Meetings

               * Travel & Reservations

               * Finance & Reimbursements

               * SOPs & Checklists

               * Personal Projects

⏰ 2. Daily/Weekly File Update
                  * Save receipts, agendas, or booking confirmations as PDF

                  * Name consistently and drop into correct folder

                  * Keep master SOPs and checklists current with review dates

________________


👥 Workflow for Team Member Collaboration
✅ 1. Project-Based Subfolders in /3_Team Projects
Structure:
CopyEdit
                     * /3_Team Projects  
                     *   /Marketing_Q3Campaign  
                     *   /Product_LaunchRoadmap  
                     *   /HR_NewHireOnboarding


Include:
                     * A “📄 Project Index” document listing goals, contacts, status

                     * Live working docs, presentations, briefs, and meeting notes

                     * Permissions: “Editor” for contributors, “Viewer” for the executive

🔄 2. Regular Maintenance
                        * Review project folders monthly

                        * Move completed work to /4_Archives/[ProjectName]

                        * Notify team members if access or file locations change

❌ What NOT to Do
                           * Don’t upload documents without naming or categorizing

                           * Avoid storing files only in “My Drive” – use shared folders

                           * Don’t give edit access to sensitive files without review

                           * Never delete executive files without written confirmation

                           * Don’t leave personal files in team-shared drives

________________


✅ Best Practices
                              * Star frequently used folders and docs for quick access

                              * Use comments instead of email attachments when reviewing drafts

                              * Create document templates in /5_Templates for consistency

                              * Use Google Drive search operators (owner:, type:, etc.) to locate files quickly

                              * Color code or emoji-label key folders for visual navigation
