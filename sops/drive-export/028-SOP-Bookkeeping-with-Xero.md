________________


🧾 Objective
To outline the correct, consistent process for performing basic bookkeeping tasks using Xero as an Executive Assistant—ensuring accurate records, timely reconciliation, and clear financial visibility for the Executive or business owner.
________________


🧩 Scope
This SOP applies to all basic financial duties managed by the EA within Xero, including:
   * Categorizing and reconciling transactions

   * Uploading receipts and documentation

   * Managing expense claims

   * Generating basic financial reports

   * Collaborating with accountant or bookkeeper

________________


🧑‍💼 Responsibilities
As the Executive Assistant, you are responsible for:
      * Entering and organizing financial data in Xero

      * Reconciling bank and card transactions weekly

      * Uploading and tagging receipts/invoices

      * Flagging issues or irregular transactions for review

      * Assisting the accountant with monthly or quarterly close

________________


🔁 Workflow for Basic Bookkeeping
________________


✅ 1. Log In and Review Dashboard
         * Go to: https://login.xero.com/

         * Select the correct organization if prompted

         * Review dashboard widgets:

            * Bank Accounts: Any unreconciled items?

            * Invoices: Outstanding bills or unpaid invoices?

            * Expense Claims: Any awaiting approval or reimbursement?

________________


📥 2. Reconcile Transactions
Frequency: Weekly (e.g., every Friday)
🔹 Navigate to:
Accounting → Bank Accounts → [Bank/Credit Card Name] → Reconcile
🔹 Steps:
               1. Review each transaction line

               2. Assign the correct Account Code (e.g., Meals, Office Supplies, Travel)

               3. Add or confirm a Description

               4. Match with the correct invoice or receipt if available

               5. Click “OK” to reconcile

❗ Tip: Use “Discuss” if you’re unsure about a transaction. Add a note for the accountant or executive.
________________


📄 3. Upload Receipts and Documentation
🔹 Option A: Upload manually via desktop
                  * Go to: Business → Bills to pay or Receipts

                  * Click Upload Files

                  * Attach PDF or image of receipt

                  * Link it to the matching transaction or bill

🔹 Option B: Use the Xero Mobile App
                     * Snap photos of receipts while traveling or spending

                     * Auto-syncs to desktop

                     * Add details like date, description, and account

✅ Always include:
                        * Vendor name

                        * Date of purchase

                        * Total amount

                        * Business purpose

________________


💳 4. Record and Manage Expense Claims
If the Executive or a team member needs reimbursement:
🔹 Go to:
Business → Expense Claims → New Claim
🔹 Steps:
                           1. Upload receipt(s)

                           2. Fill in fields:

                              * Date

                              * Amount

                              * Expense Category

                              * Description (e.g., "Client dinner – June 4")

                                 3. Assign to correct user (e.g., [Executive Name])

                                 4. Submit for approval or mark as reimbursed (if applicable)

🔄 Track reimbursement status weekly if handling reimbursements yourself.
________________


📤 5. Issue or Record Invoices (Optional Task for EAs)
If supporting invoice creation:
🔹 Go to:
Business → Invoices → New Invoice
Fill in:
                                    * Customer name

                                    * Date & due date

                                    * Item or service description

                                    * Amount

                                    * Tax settings (GST/VAT if applicable)

Click Send or Approve, depending on workflow.
________________


📊 6. Generate Basic Reports for Executive
🔹 Recommended Monthly Reports:
Report Name
	Use
	Profit & Loss (P&L)
	Review revenue vs. expenses
	Bank Reconciliation Summary
	Confirm all transactions are matched
	Expense Claims Summary
	Track submitted and reimbursed claims
	Account Transactions
	View categorized transactions by code
	🔹 Steps:
                                       * Go to: Accounting → Reports

                                       * Choose report (e.g., Profit & Loss)

                                       * Set the correct date range (e.g., “June 1–June 30”)

                                       * Export as PDF or Excel

                                       * Share with Executive by email or save to:
📁 /2_EA_Admin/Finance/Reports/[Month-Year]_P&L_Report.pdf

________________


📅 7. Collaborate with Accountant or Bookkeeper
Monthly Tasks:
                                          * Flag any unclear transactions in Xero for review

                                          * Upload missing documents before month-end close

                                          * Share updated receipts folder link (if using Google Drive)

                                          * Confirm that all bank feeds are syncing properly

💡 Tip: Create a recurring task:
“Finance Check-In – Last Friday of Month”
________________


✅ Best Practices
                                             * Reconcile transactions weekly—don’t let them pile up

                                             * Name and organize receipts consistently (e.g., 2025-06-10_Uber_SFMeeting.pdf)

                                             * Double-check categories—incorrect codes lead to messy reports

                                             * Limit manual entry by using bank feed + Xero mobile app

                                             * Maintain shared Drive folder for receipts and statements:
/2_EA_Admin/Finance/Receipts/2025/06_June/

________________


❌ What NOT to Do
                                                * ❌ Don’t guess account codes—ask if unsure

                                                * ❌ Never delay reconciling past month-end

                                                * ❌ Don’t delete transactions unless instructed by an accountant

                                                * ❌ Avoid uploading personal or unclear receipts

                                                * ❌ Never approve an expense claim without supporting documentation
